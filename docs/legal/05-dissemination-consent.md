# Согласие на распространение персональных данных

Это согласие оформляется отдельно от любых иных документов до первой публичной публикации.

Оператор: `[НАИМЕНОВАНИЕ, АДРЕС, САЙТ]`. Информационный ресурс: `[URL]`.

Субъект разрешает распространение только отмеченных категорий:

- `[ ]` псевдоним;
- `[ ]` имя;
- `[ ]` аватар;
- `[ ]` сведения публичного профиля;
- `[ ]` авторство рецептов, комментарии и реакции;
- `[ ]` репутация и достижения;
- `[ ]` иное: `[УКАЗАТЬ]`.

Запрещено по умолчанию распространять email, телефон, точный адрес, платёжные данные, данные безопасности, семейные данные, чеки, историю питания и сведения о здоровье.

Условия и запреты субъекта: `[ПОЛЯ ДЛЯ КАЖДОЙ КАТЕГОРИИ]`. Передача неограниченному кругу лиц через интернет: `[ДА/НЕТ ПО КАЖДОЙ КАТЕГОРИИ]`. Срок: до отзыва или снятия публикации.

Субъект может прекратить распространение через настройку видимости и требование на `[КАНАЛ]`. Оператор прекращает распространение в установленный законом срок, сохраняя только данные, необходимые для законной защиты прав и исполнения обязательных требований.

Версия, полный текст, выбранные категории/условия, дата, субъект и доказательство волеизъявления фиксируются неизменяемо.
