| Термин                  | Определение                                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Системный ингредиент    | Базовый нормализованный продукт в каталоге                                                                                |
| Вариант ингредиента     | Уточнение системного ингредиента                                                                                          |
| Брендовый товар         | Товар конкретного производителя                                                                                           |
| Партия                  | Конкретный запас с количеством, датой, сроком и при необходимости ценой                                                   |
| Движение                | Изменение количества или состояния партии                                                                                 |
| Заготовка               | Домашний продукт длительного хранения                                                                                     |
| Модификатор рецепта     | Структурированное изменение базового рецепта                                                                              |
| AI-действие             | Пользовательская единица лимита: обычная задача стоит 1, расширенная 2, тяжёлая 3–5 единиц с показом стоимости до запуска |
| Семейная сущность       | Данные, доступные членам семьи                                                                                            |
| Член семьи без аккаунта | Профиль для учёта порций и ограничений без отдельной учётной записи                                                       |
| Медианная цена          | 50-й перцентиль набора цен, используемый для примерных расчётов                                                           |
| Критичная жалоба        | Жалоба на опасный контент или личные данные, вызывающая авто-скрытие                                                      |
